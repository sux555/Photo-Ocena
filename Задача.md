# Проект: Photo-Ocena

## 1. Описание
Веб-приложение для обмена и оценки фотографий студентами техникума. 
**Язык интерфейса:** Польский.
**Режим работы:** Локальный.

## 2. Технический стек
*   **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
*   **Backend:** PHP 8.x (Scripting), SQLite (Database).
*   **Особенности:** Запрещено использование комментариев в коде. Разделение логики (PHP) и представления.

## 3. Функциональные требования
1. **Система аккаунтов:** Регистрация и авторизация.
2. **Взаимодействие:** Лайки и дизлайки для фотографий.
3. **Рейтинг:** Таблица лидеров по количеству лайков.
4. **Загрузка:** Форма загрузки фото (лимит 5 МБ).
5. **Персонализация:** 
    *   Изменение аватарки и редактирование профиля.
    *   Настройка дизайна (выбор акцентных цветов/тем).
    *   Возможность отключения спецэффектов в настройках.

## 4. Дизайн и UX
*   **Стиль:** Минималистичный черный фон с белыми акцентами.
*   **Эффекты:** Плавные переходы, свечение (glow), анимированный логотип (SVG/CSS). Не перегружать!
*   **Адаптивность:** Игнорируем (только десктопная версия).

## 5. Безопасность и ограничения
*   **Лимиты:** Максимум 2 фото в минуту, размер файла до 5 МБ.
*   **Защита входа:** Ограничение попыток авторизации.
*   **Хеширование:** Использование `password_hash()` (BCRYPT) для защиты паролей.

## 6. Задачи для PHP
*   Управление сессиями, профилями и настройками дизайна.
*   Работа с базой данных SQLite (сохранение данных и рейтинга).
*   Логика анти-спама и проверки лимитов загрузки.
*   Обработка и безопасное хранение фотографий.
